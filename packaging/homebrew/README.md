# DrXendria Homebrew Tap

Official Homebrew tap for macOS applications by [DrXendria](https://github.com/DrXendria).

## Install Aegis Vault

```bash
brew install --cask drxendria/tap/aegis-vault
```

Or tap first:

```bash
brew tap drxendria/tap
brew install --cask aegis-vault
```

## Available Apps

| App | Command | Description |
| :--- | :--- | :--- |
| **Aegis Vault** | `brew install --cask drxendria/tap/aegis-vault` | 100% local, two-layer zero-knowledge password manager |
