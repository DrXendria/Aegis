## 🌟 Özellikler

- **🔒 İki Kademeli Güvenlik:** Firebase bulut entegrasyonu ile cihazlar arası senkronizasyon, **Yerel Master Şifre** ile kırılması imkansız cihaz içi (local) uçtan uca şifreleme.
- **🌍 Çoklu Dil Desteği:** Türkçe, İngilizce, Almanca, İspanyolca, Fransızca, Rusça, Çince, Arapça, Japonca ve çok daha fazlası dahil 20 dil seçeneği!
- **💱 Küresel Para Birimleri:** Aylık abonelik giderlerinizi hesaplamak için TRY, USD, EUR, GBP, BRL, SAR, AED gibi tüm ana para birimleri desteklenir.
- **✨ Şık Arayüz:** Modern "Glassmorphism" tasarımı, akıcı mikro-animasyonlar ve özel tasarım bileşenleri (custom dropdowns vb.) ile kusursuz bir kullanıcı deneyimi.
- **📦 Tek Dosya ile Kurulum:** Arkadaşlarınızın veya kullanıcıların kodla uğraşmasına gerek yok. Tek bir `.exe` (setup) dosyası ile hızlıca kurulur ve çalışır.

## 🚀 Hızlı Kurulum ve İndirme

Aegis'i kullanmak için kodları indirmenize veya karmaşık işlemler yapmanıza **gerek yoktur.** 
Sadece **[Releases (Sürümler)](#)** sayfasına gidin, en güncel `Aegis_Setup.exe` dosyasını indirin ve kurun! (Kendi web siteniz açıldığında buraya indirme linkini ekleyebilirsiniz.)

*Tüm uygulama tek bir çalıştırılabilir dosya içerisine (standalone) paketlenmiştir.*

## 🛠 Geliştirme (Development)

Eğer projeyi kendi bilgisayarınızda derlemek veya geliştirmek isterseniz:

### Gereksinimler
- Node.js (v18+)
- Rust (Cargo)
- Tauri CLI

### Kurulum
```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirici modunda (Hot-Reload) çalıştırın
npm run dev

# Tauri ile masaüstü uygulaması olarak derleyin (Setup dosyası üretir)
npm run tauri build
```
